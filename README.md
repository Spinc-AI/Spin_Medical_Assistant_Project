# دستیار پزشکی اسپین (<span dir="ltr">Spin Medical Assistant</span>)

یک دستیار **پشتیبان تصمیم‌گیری پزشکی** فارسی‌زبان، با معماری **ماژولار و مبتنی بر <span dir="ltr">API</span>**. یک مدل زبانی مرکزی (**<span dir="ltr">Core_LLM</span>**) در میان مجموعه‌ای از **ماژول‌های** مستقل قرار می‌گیرد (تبدیل گفتار به متن، و در آینده تبدیل متن به گفتار، تحلیل سی‌تی‌اسکن، تحلیل احساسات و …). یک **ارکستریتور (<span dir="ltr">Orchestrator</span>)** تصمیم می‌گیرد که هر ورودی به کدام ماژول داده شود، با چه چیزی، و خروجی آن چه شود — و با همه‌ی اجزا از طریق <span dir="ltr">API</span> ارتباط می‌گیرد.
